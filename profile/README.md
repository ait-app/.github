Ait brings agent sessions, files, code changes, and a terminal into one workspace. Connect the computers and servers where your projects live, choose the agent that fits each task, and continue from your desktop, phone, or browser.

## What you can do

- **Use the agents you already know** — work with Codex, Claude Code, OpenCode, DeepSeek Harness, Antigravity CLI, Pi, Oh My Pi, and MiniMax Code in one interface.
- **Work across hosts** — connect multiple computers and servers while each host keeps its own files, tools, and development environment.
- **Continue across devices** — start on a computer, check progress from another screen, and respond to approvals when you step away.
- **Review work in context** — keep conversations, files, diffs, and a terminal together from the first task to a reviewed commit or pull request.
- **Run tasks in parallel** — use separate sessions and Git worktrees for independent changes.
- **Keep a lightweight host available** — run the standalone Rust daemon on a small-memory Linux server or an always-on Mac.

## Get started

1. Install Ait from the [download page](https://ait-app.com/en/download/).
2. Follow the [quick start](https://ait-app.com/en/docs/quick-start/) to connect an agent and create your first workspace.
3. Read [Why Ait?](https://ait-app.com/en/docs/why-ait/) for the product model and [Connections & data](https://ait-app.com/en/docs/connection/) for remote access details.
